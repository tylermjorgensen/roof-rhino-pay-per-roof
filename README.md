# Roof Rhino — Pay Per Roof™

Sales-call presentation page and master operational flowchart for the Pay Per Roof™ acquisition model.

## Contents

- `index.html` — responsive sales presentation page
- `styles.css` — site styling and responsive rules
- `script.js` — progress, modal, reveal, and checklist interactions
- `artifacts/diagrams/pay-per-roof-engine.d2` — editable master flowchart source
- `artifacts/diagrams/pay-per-roof-engine.svg` — web/vector flowchart
- `artifacts/diagrams/pay-per-roof-engine.png` — high-resolution flowchart export
- `qa/visual-qa.json` — desktop/mobile and diagram QA record
